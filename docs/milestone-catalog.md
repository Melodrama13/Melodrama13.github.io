# 里程碑名称与口径

更新日期：2026-10-23。以下为“本期纪录”全部 48 种可能出现的徽标名称；数量、角色、花色及活动显示在纪录正文。查先例的“首次达成／全员达成”为查询结果分区，不属于此名称表。

活动面板包含“活动详情／查先例／本期纪录”三页。活动行右下角的 i 打开该活动详情，顶部“先例”入口也可切换到详情；详情与本期纪录共用所选活动，切页保留查询条件与结果。详情按活动概览、WL 篇章（若有）、卡池与卡片、复刻记录、书下曲展示。概览使用 Ban 代表色纯色淡填充及 `chibi` 全身图；分团 VS 图片统一为与 `chibi_s` 相同的命名。编号后依次展示合并活动类型与角色箱／混次数的标签、节日；箱／混标签复用活动页 `getEditorSeriesStyle` 的团体色／混活渐变规则。小屏 Ban 位于左侧，右侧按编号／箱混／节日、活动标题排列，箱混采用角色与次数的简写；完整分类保留在提示中。日期独立成行，花色与团体小图标分别悬于右上、右下角，不占网格位置；不另展示登场 VS，时区统一标记 UTC+8。

卡片包含已实装的四星、独立 CFES／BFES 分组和活动报酬；FES 位于当期卡池之前，初始低星卡列为其他卡片。花前／花后复用先例依据的方形卡面、星级边框和左上花色角标，遵循二星及特殊单卡面规则；不再显示花前／花后文字，图片替代文本仍保留状态，单卡面与卡片名称居中。限定类型复用年份统计的红色斜缎带，星级位于卡面左下角，VS 附属团体图标位于右下角，OC 不显示附属团体。

详情卡片在宽面板中采用四列宽度，随面板变窄依次调整为三列、两列和单列；一对卡面宽度不超过 184px，中屏以下不超过 156px。角色名与技能胶囊优先同行，空间不足时整块换行，不拆姓名或留下分隔点。卡名、编号与实装日期为辅助信息，编号只显示 `#xxx`；卡池类型使用不同颜色的填充胶囊。FES 分组使用加大的图标。星级图片按卡面状态选择：花前统一使用黄色星星（ystar），花后统一使用彩色星星（rstar），与卡片星级无关；仅花后的特殊卡同样使用彩色星星。

概览、卡片、WL 篇章、复刻与歌唱版本信息块，以及分类、节日、技能、卡池类型、MV 和难度胶囊，统一复用 CSS-only Chip 玻璃材质。边缘高光和柔和内阴影来自全站 token；信息卡保留淡代表色并适量透光，不增加逐卡 SVG 折射滤镜。高对比度或减少透明度时使用实色背景与深色文字。复刻区只对限定及联动卡池展示；常驻或没有限定类型的活动隐藏整段，即使同期开过独立 FES 卡也不显示。

查先例与本期纪录的筛选控件、配置卡片、纪录卡、评级胶囊及依据中的活动跳转按钮使用同一材质与淡色透光填充，保留查询行为、分级颜色和紧凑排版。活动选择器菜单保留可读实色底，材质不加到外层定位容器，确保菜单可盖过纪录卡；辅助功能降级时胶囊与查询按钮同步使用深色文字。

“活动详情／查先例／本期纪录”与顶栏共用 `UiGlassTabs` 滑块组件及手势模块，支持点击、键盘激活与拖动跨页，切换继续保留活动选择、查询条件和结果；面板内部采用不追加折射的 contained 模式。书下曲难度胶囊保留六种难度色，以淡色透光底、同色系深色文字和细边框替代整块高饱和填充，使数字与玻璃边缘更清晰。

详情的箱／混活分类标签沿用同样的淡色玻璃方案，保留箱活的团体色与混活的三色渐变，文字加深；WL 分类采用相同规则。总集篇标签统一显示“总集篇 · 团体缩写”，与 WL1／WL2 一样采用对应团体的淡色玻璃填充。活动列表和预测编辑器的分类标签仍使用原配色。

活动时分由 `getHistoryEventPeriod` 按北京时间生成，原活动 JSON 继续只存日期。正常箱／混／总集篇为 14:00–19:59，所有测试活动为 20:00–19:59，WL 含终章为 19:00–18:59；已对照本地原始 `events.startAt/aggregateAt` 的 221 条记录。延期修复的历史开启特例仅为 #120 19:00、#145 17:00、#172 16:00，结束仍为 19:59；原始秒数 59 省略为分钟精度。`closedAt` 是活动页面关闭节点，不能用作打歌结束。非数字的纪念／联动卡池条目只展示已有日期，不套活动时分；复刻继续展示已有日期。

WL 篇章使用 `public/data/pjsk_wl_chapters.json`，仅打开 WL 详情时加载并缓存，失败可重试，不增加首页必需数据请求。文件只保存活动关联 `event_id`、按顺序排列的篇章数组以及角色中文姓名、UTC+8 起止时间字符串；不保存角色数字 ID、类型或毫秒戳。篇章行使用角色代表色的 18% 填充，标题旁仅标记 UTC+8。自动同步用 `normalizeWorldLinkChapters` 将上游顺序、角色及时间转换成本站格式，文件参与公共数据版本计算。当前 19 期共 80 篇章，WL3 保留实际跨团角色顺序，#180／#218 的终章角色为空。[字段与同步说明](world-link-chapters.md)。

c6 歌限联动卡的左侧展示对应曲绘，右侧沿用仅花后的卡面；曲绘不重复显示曲名，替代文本仍保留歌名。依据 [SEGA The Music Style 公告](https://prtimes.jp/main/html/rd/p/000007538.000005397.html) 与现有六组资料核对后，歌限卡通过 `CardName` 与已实装歌表 `title` 精确对照（去除首尾空白）；仅对 `SONG_LIMITED_GACHA_IDS` 登记的卡池启用，同名有歧义或没有匹配时不展示曲绘，无需额外映射 JSON 或硬编码卡片 ID。

书下曲关联现有歌表，展示曲绘、别名、词曲编曲、UTC+8 实装时间、MV 类型、谱面难度和已实装的歌唱版本；不重复标注原创书下曲。MV 标识位于曲名右侧，曲绘与介绍纵向居中，实装时间与创作者采用相同字号，难度胶囊沿用歌曲页六种难度颜色。原始 `releaseDate` 的 JST 时间显式换算为 UTC+8。歌唱者优先使用角色图像，外部歌手保留姓名以避免请求不存在的图片；未来版本按其 `released_at` 日期隐藏。

“查先例”按达成、连续、期间组织。达成默认保留普通达成与后来追平，可勾选“仅里程碑”；间隔始终只反查真实历史突破。连续和期间按具体序列、月份／自然年／运营年组合条件；月份复用永久年月键，特殊来源按覆盖最多月份归属。已有里程碑名称、评级和依据保持一致，新增查询结果不自动分配评级或写入本期里程碑。

## 评级与展示顺序

按金、银、铜排序，同级保留原有顺序。整张卡片边框与胶囊使用对应评级色（金为偏黄金色、银为冷灰、铜为红棕色），评级框线宽度为 2px，并用小圆点辅助识别，顶部保留图例，悬浮说明和可访问描述包含评级。同次合并多个首次时，按其中最高等级展示。

| 评级 | 项目 |
|---|---|
| 金 | 四星、限定、报酬、百六限定新上限；所有间隔新纪录；OC／VS任意花色的新上限；全员五色补齐（含全OC范围）；同池配置首次 |
| 银 | 分卡、P分、普分、奶卡、判卡、三星、二星、限Ban、箱限Ban、混限Ban新上限；OC／VS具体单色新上限；团体五色补齐；首次同池 |
| 铜 | Banner、箱Ban、混Ban、百六限Ban、百六箱限Ban、百六混限Ban新上限；个人五色补齐；角色／花色技能首张；其他条件的首次同池；同色连出新上限 |

“同色连出”按每个角色四星卡的实装顺序计算连续同花色张数，其他花色四星会中断，二／三星及没有该角色四星的活动不打断；同刻实装多个花色时中断。当前记录突破该角色自身历史最长连出的一刻。例如紫月、紫月、紫月为连续 3 张，下一张绿草即中断。先前有紫月三连后，绿草三连仅为追平，不生成纪录；绿草四连才产生新的铜级纪录。
