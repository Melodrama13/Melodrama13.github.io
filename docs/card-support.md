# 支援配队

支援分沿用现有公式：最高技能倍率 + 其余四张技能倍率之和 / 5。仅比较技能分值，不考虑综合力、歌曲和难度；卡片范围沿用卡片统计页所选的截止活动。

## 总集篇

支援配队标题旁的“总集篇”复选框默认关闭。关闭时使用原有配队规则；打开后，五个 OC 团分别使用以下条件：

- 该团四位不同的 OC 各一张，以及一张归属于该团的虚拟歌手卡。
- 五种花色分别计算同色最优配队，不为总集篇指定某一种活动花色。
- 原有“WL配队”开关独立控制 WL 行。开启后，WL 行须同时满足上述五人组成与五种花色各一张。
- 缺少任何一位 OC、本团 V 或无法组成五色时，该行显示空位，不用其他成员或重复花色补齐。
- 团分技能按完整同团五人计算。技能和整队同分时继续沿用原有 BFES、CFES 与新卡优先顺序。

VS 团的同色配队、WL 配队及“原v队”选项沿用原规则。

总集篇五人均属于同团，技能倍率与其他成员所选花色无关。求解时先保留每位 OC、每种花色的最佳卡，以及每种花色的最佳本团 V；WL 再枚举全部可行花色分配，最多比较 5! 个完整组合，不使用普通 WL 的候选截断。

切换开关沿用页面的阅读位置固定行为。全板块与单团 PNG 导出使用当前选中的配队规则，复选框沿用现有的导出隐藏样式。
