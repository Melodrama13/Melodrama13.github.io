# pjsk-planner 用户手册

本项目是面向《世界计划》的非官方数据浏览与预测辅助站点，提供活动、卡片、乐曲三大页面，并带有本地预测数据源管理。

## UI 开发规范

维护者请参阅 [UI 开发规范](docs/ui-system.md)、[代码结构与命名约定](docs/code-conventions.md) 和 [滚动导航规范](docs/scroll-navigation.md)。

## 开发脚本与数据同步

- `scripts/` 保存随公开仓库发布的构建插件和 UI 检查脚本，作用见 [脚本说明](scripts/README.md)。
- `sync-scripts/` 保存私有的数据抓取、活动/卡片/歌曲同步及图片同步脚本，整个目录由 Git 忽略。脚本内容在 `Melodrama13/pjsk-planner-sync-private` 私有仓库维护。
- `.sync-private/` 是 GitHub 自动同步任务检出私有仓库的临时目录，本地开发通常没有这个目录；它也由 Git 忽略。

在本地使用同步命令前，将私有仓库 `scripts/` 中的 `.mjs` 文件放入本站的 `sync-scripts/`。例如 `npm run fetch:other-source` 抓取源数据，`npm run sync:songs-other:dry` 预览歌曲同步结果。现有同步命令名称仍可照常使用；CI 会自动将私有脚本安装到该目录。

## 页面总览

桌面端顶部导航、手机端底部悬浮切换栏均可进入 3 个页面：

- 统计面板：角色卡片统计、节日人选、间隔记录、特殊统计。
- 历史活动一览：活动时间轴、筛选、预测编辑与悬浮统计。
- 乐曲统计：多维乐曲统计与乐曲检索。

## 设置与数据源

三个主页面均可打开设置：桌面端齿轮按钮位于顶栏右侧，手机端位于底部切换栏右侧。面板使用「全局设置 / 数据源」两页切换，内容超出可用高度时可在面板内滚动。数据源页仅在活动页可切换，离开活动页自动回到全局设置。预测编辑器头部也提供设置入口；编辑期间可以调整显示偏好，数据源操作保持禁用。

全局设置包括：

- 卡面样式：V1 / V2，默认 V2，统一卡框和卡面上的属性图标。
- 单卡面显示：花前 / 花后，默认花后，适用于统计与活动先例依据中的单张卡面。特殊卡自动回退到已有卡面，详情双卡面仍同时显示。
- 名称格式：缩写 / 单字，默认单字，统一卡片统计中的角色简称与相关标记，移动端同样生效。
- 外观模式：浅色 / 深色 / 系统，默认系统。系统模式跟随设备的深浅外观变化，三个页面、设置及浮层统一切换；已保存的手动选择会保留。
- 显示剧透：默认关闭，继续遵守卡面、歌曲与声线的展示时间；开启后可提前查看这些内容及玩偶统计中的未来卡面。切换即时生效，不改变活动开始与预测截止判定。本地调试和线上使用同一开关，不再根据访问地址自动放行。

设置使用 160px 宽的胶囊滑块，选中项在透明玻璃高光与边缘阴影上叠加少量灰色底色；悬停或点击圈问号可查看浮动说明，不撑开设置面板。卡面预览固定使用 #289，角标按各处原有规则自动显示。偏好即时生效并保存在当前浏览器，独立于预测数据源。名称格式和花前／花后控件已从统计导航移至全局设置。

数据源页保留以下操作：

- 导入：导入 JSON，作为新的预测数据源。
- 导出：导出当前数据源。
- 预测截图：导出预测区间 PNG，可选择是否包含生日行。
- 新建：新建空白数据源，或复制当前数据源。
- 删除：删除当前数据源（至少保留一个数据源）。
- 重命名与排序：支持重命名、上下移动和拖拽排序。

用户名会用于导出命名和本地数据源命名。

## 历史活动一览

历史活动页用于查看活动列表、编辑预测以及快速观察统计结果。

核心能力：

- 活动导航：可快速跳到当前活动。
- 筛选面板：支持活动筛选与卡片筛选两种模式。
- 常用筛选条件：活动类型、卡池类型、活动节日、活动属性、活动团体等。
- 联动卡池显示切换：可隐藏或显示联动卡池。
- 预测状态标记：区分待预测与已预测。

先例与纪录：

- 点击活动页工具栏的“先例”，可展开检索面板；点击已开活动右下角的圆形 i，直接查看该期里程碑。
- “查先例”分为达成、连续、期间、配置四个入口。达成保留全部数量维度、花色四星、五色补齐与技能首张；连续支持出四星／未出四星、出报酬／未出报酬、出卡、双人同池、同类型卡、书下同 V、同团 Ban 和花色缺席；期间支持月份、自然年、运营年与零次、最多／最少、指定次数。间隔项目只反查真正的历史突破，默认显示最高纪录，可展开历史过程。
- “配置”以每张卡为一个条件，分别选择星级、技能、花色、附属组合，支持添加、复制和删除，不再提供角色组合查询。不同条件必须由不同实际卡片满足，重叠条件使用完整匹配分配；未指定卡片不限。四星来自完整具体卡池，二／三星只来自当期报酬，报酬不增加 UP 数；联动报酬使用共用开关。附属 V 按卡片 Affiliation 归团。UP 数、活动与卡池在顶部，UP 极值自动生成，FES 可选且保留早期分池与 WL3。已知未来四星会使对应具体池暂不参与，关闭 FES 不会被未来 FES 延迟。标题简写为“3UP · 2P分＋1奶卡”；依据保留完整四星池及匹配报酬，命中卡高亮。角色组合仍可使用活动筛选，首次同池里程碑保持原有口径。
- 连续的“箱活”位于“混活”上方；双人同池的本人箱活有独立箱主选择，箱主不必为同池两人之一。同团 Ban 的本人箱活按箱主分别统计，保留团体主体。同类型卡可选个人四星或个人全卡，再选同色／同技能；完整个人流中的异色／异技能会中断连续，同时发行的异值卡不凭空排序。个人全卡默认不计生日卡，可勾选计入并按真实花色／生日技能判断，独立生日来源不进入原里程碑 ledger。书下同 V 不计 WL 且无相关开关。仍在连续／已结束使用独立状态胶囊。所有入口的结果选择器统一紧邻查找按钮左侧，默认全部，仍需点击查找才更新。
- 各入口按项目、范围、角色及观察条件组织筛选项；手机按字段数量平衡为两至三列，面板变宽后采用四至六列，配置的卡片条件块在宽屏两块并排、每块四项同排，手机四项分两行。卡片与活动限制由浅线分隔，更多条件集中放补充复选项。花色可选任意、全部或指定花色，数量按 1～MAX 自动生成并倒序排列，以“7(MAX)”“6(MIN)”标注极值且不重复列出，默认选择 MAX。数量与花色同时显示达标人数；花色的全员达成放在首次达成下方，同刻最后补齐者合并为一张卡片，展示角色、花色、日期和活动，以及首次至全员达成的耗时；指定个人时不重复展示全员达成。
- 月份优先解析 `pjsk_prediction_order.json` 的永久年月键；无键来源取覆盖天数最多的月份，并列取后一月。自然年默认新年计入下一年，运营年复用统计页周年边界。年份与月份选项随已开活动生成，包含进行中的自然年、运营年；所有期间默认勾选“统计非完整期间”，计入开服首期及进行中的期间并标注；取消后仅比较完整期间。连续 N 期始终要求已存在 N 个正式数字活动，不足 N 期的尾段不参与。连续保留范围内的未命中活动，不计入 FES 不会删除该期；WL／联动可选，跨团双人可沿全部活动或混活查询。连续次数提供 MAX 和明确数字，数字 N 表示恰好 N 次，不将最小数字转成 MIN；每段连续只展示一次。期间的“每期都有本团四星”使用有正式数字编号的活动作为分母，终章与总集篇计入，测试活动不计入，非数字联动永不占一期活动；月份、自然年、运营年、动态年自动计入期间的联动卡，连续 N 期另提供“计入联动”，仅影响卡片数量。报酬另受共用的“报酬计入联动”控制。书下依据复用歌曲封面的路径与资源加载方式。
- 查先例打开时不查询，必须点击“查找”；改动条件及复选框后保留上次结果并提示待查询，切换项目清空旧结果并将次数重置为 MAX。次数及 MAX／MIN 随当前条件和已开数据生成，无需维护数字列表。更多条件按结果、活动与时间、卡片来源、计数口径、角色归属分组，以浅线分隔，只展示相关选项。
- 期间的卡片项目包含四星、三星、二星、报酬、同团四星，活动项目包含 Banner、同团 Ban，分卡、P分、普分、奶卡、判卡等移到独立技能下拉，可组合“四星＋分卡”“三星＋奶卡”等。分卡沿用团分开关；Banner／同团 Ban 不显示技能并清空隐藏技能条件。限定和百六不单列项目；四星／Banner 选择限定后可进一步选择百三／百六。活动与卡片／卡池类型同排：卡片项目按每张卡自身类型筛选，Banner／同团 Ban 按活动卡池筛选；百六依据普通限定卡池中存在 FES 卡判断，不依赖 Ban 主。同团四星固定计入本团 V，按卡片副团体将附属 V 归入对应 OC 团；原 V 才归 VS。移除归属开关，计入 FES 默认开启且可关闭。
- “达成”默认选择全角色、任意花色、MAX 和全部记录。任意花色取每人最多的一色，全部花色取每人最少的一色，再在人物范围内取 MAX／MIN；进度按人数去重。四个入口均默认全部，并在匹配结果的最早／最晚时点分别标明“首次达成／最近达成”，保留同时达成者和原有里程碑标签。“全部”结果统一先显示首次、再显示最近，其余按达成时间倒序；并列边界记录全部保留，同时属于首次与最近的记录只出现一次，分页后仍优先看到重点。“配置”默认一个四星任意条件，未点击查找不运行；WL3 完整保留 5／6 UP，附属组合由每张卡单独指定。“本期纪录”默认选择当期已开活动，随开放时间更新，并保留手动选择的历史活动。查先例的口径复选框直接放入更多条件，不嵌套第二层折叠。
- 期间另支持动态年与连续 N 期，保留零次和并列结果。动态年从每期活动日期起算一个日历年，结束日期不计入，闰日按下一年二月末对齐；连续 N 期按常规活动滑动，默认 3 期，可输入 7、8 等任意正整数，完整窗口要求第 N 期结束。默认计入非完整期间，取消勾选后要求窗口已结束；连续 N 期无论该开关状态如何都必须有 N 个正式数字活动。同一对象、同一组依据的重叠动态窗口合并成一张结果，保留全部适用窗口及首次／最近标记，零次的不同中断区间仍分开。年类标题统一为“1 年 7 四星”，下方标明自然年／运营年／动态年。标题根据活动与卡片／卡池组合显示常驻、限定、普箱、普混、箱限、混限等前缀，百三／百六置于最前。没有额外动态月，按活动月的查询仍复用永久标识。
- 书下同 V、同团 Ban、花色缺席的依据均显示实际条数；同团 Ban 列出每期 Ban 主卡面，遵循全局花前／花后偏好，花色缺席保留两端及中间所有活动，无 Ban 主时使用团体图标。勾选计入 WL 后，无固定活动花色的 WL 计入缺席期数，但不视为某个固定花色出现；普通活动属性未知时仍中断判断。所有卡面沿用 64px 稀有度框与花色图标比例、活动简称胶囊跳转及日期。
- 历史查询使用已开基础卡片，不受当前预测源及活动列表筛选影响；数量查询可含低星及报酬，其余卡片条件按对应口径计算。“本期纪录”分为首次达成、间隔纪录、花色达成、首次同池四类。首次达成沿用阶梯分布的 14 个基础指标，三个 Banner 指标各自扩展箱活／混活／全活动，形成 20 个数量维度（四星、限定、分卡、P分、普分、奶卡、判卡、二／三星、报酬、Banner、限Banner、百六限定、百六限Banner），统一记录全角色新上限；Banner 仅有 OC 参与，报酬保留二／三星拆分。花色上限在 OC／VS 范围内分别记录单色及任意花色的首次新高，同次达成保留一张卡片与金／银两个标签，不记录个人追平。数量与花色突破保留上一阶的首次时间、并列角色和活动，起终点对称展示，计算突破耗时；同刻跨阶计 0 天。
- 间隔比较四星、限定、箱活Banner、混活Banner、全部Banner；所有角色统一比较，只显示严格打破历史最长／最短的已结束区间，天数与期数分别判定，同次双破合并展示。花色达成包括 OC／VS 范围内的花色上限首次、个人／团体／全员五色补齐、角色各花色技能首张及同色连出；团体补齐要求每位成员五色都达标，使用团体圆形 logo，标明最后贡献者与上一补齐阶的用时。首次同池仅含四星，保留首次箱活／混活／联动／限定同池条件，团 WL（WL1／2）按箱活、混 WL（WL3）按混活计算，不单列 WL 纪录，区分 VS 归属；18、27 期 FES 分池，技能配置首次归入此类。
- “口径选项”以紧凑八项控制限定计入 WL3／歌限、分卡计入团分、报酬计入联动、二／三星仅报酬、百六计入 FES、同池计入 FES／仅计入本团 V；同池仅计入本团 V 默认开启，仅在活动有 Banner／Unit 时生效，不跟随统计页临时状态。Banner 箱／混／全活动自动并行判断。限定数量使用共享限定规则；限定同池计入 WL 和联动，FES依同池选项。低星依据使用对应稀有度边框，保留横向卡图、活动简称跳转及日期。
- CFES／BFES 不生成角色花色技能首次或同技能配置首次；对应卡片仍参与数量、花色、同池及百六相关统计。
- 同池的联动判断与统计页共用活动类型规则，包含歌限 c6，后续新联动无需追加编号白名单。
- “查先例”和“本期纪录”共用随面板宽度切换的单列／双列布局；宽屏仅一条结果时，纪录概览与时间线左右排列。达成记录与全员达成分别适配，全员进度条保持整行。起终点用空心／实心圆点和连线表示，日期、人物、活动及跳转保留；展开依据不强制相邻卡片等高。
- 里程碑按金、银、铜优先排序，同色连出为铜级；同级保留原有顺序。整张卡片边框与右上角框线上的名称胶囊（不额外占高）共同表示评级：金为偏黄金色，银为冷灰，铜为红棕色，小圆点和图例辅助识别。花色与普通数量标题统一按文字基线排版，花色突破、技能首张及同色连出标题的花色图标共用底部对齐规则（与数字基线齐平，向下 1px 作视觉补偿），同色连出以花色 logo 替代属性文字；评级边框为 2px。“查先例”和“本期纪录”均不再显示底部统计口径说明。三星／二星标签不随报酬口径改名；数量 Banner 标签简写为 Banner、限Ban、箱Ban 等，间隔标题去掉“全活动”，箱活／混活的 Banner 缩为 Ban，角标为“间隔新纪录”。同时突破任意花色与具体单色上限时，一张卡片并列展示金、银两个标签，边框及排序采用金级。单色新上限和技能标题使用花色 logo，大数字两侧保留间距。所有依据使用同一 64px 卡面规格。范围内的数量新上限、OC／VS花色新上限及间隔纪录，标题只显示项目与数量，不以达成者姓名开头；达成者保留左侧头像、姓名提示及依据。个人五色补齐、技能首张、同色连出保留姓名，团体纪录保留团体名称；查先例的个人达成结果也保留姓名。完整名称及评级见 [里程碑名称与口径](docs/milestone-catalog.md)。
- 结果以 20～22px 核心数字、14～15px 纪录标题、12px 活动简称与 11px 日期分层；间隔只强调实际破纪录的天数／期数，旧值、此前纪录及单位降低视觉权重。结果卡增加稳定底色，状态标签轻填色；概览、时间线与依据使用浅分隔线，宽屏横排时切换为竖线。
- 活动选择可下拉或输入编号（如 `#220`）、简称（如 `奏3箱`）；数字活动标签显示编号、已有简称及标题，部分或歧义输入不会自动切换。时间线使用 18px 小头像代替角色姓名，悬停及替代文本保留全名。
- 纪录的“三星/二星仅报酬”合并并默认勾选，联动默认不计。统计页二／三星的“报酬”也共用默认开启状态，勾选后在其后显示“统计联动”；二星、三星和报酬总数的联动开关共用默认关闭状态，数量、排序及团体汇总同时遵循该口径。报酬的二／三星组成仅放在依据中；间隔依据按本次／此前纪录分组，用头像、数值和横向两端卡面对应保持者、活动简称与日期，同一旧区间的天数和期数保持者合并。

预测编辑：

- 打开某活动后可进入预测编辑器。
- 可配置活动类型、卡池性质、活动属性、Ban 主。
- 可编辑阵容中的角色、稀有度、属性、技能。
- 支持 World Link 特殊规则（人选锁定、仅调整属性等）。

悬浮统计：

- 预测编辑打开时，可启用悬浮统计面板。
- 可选择最多 6 个统计面板显示。
- 支持拖动、收起、重置布局。
- 可配置属性统计人选、日挑配队人选、节日单选等。

## 统计面板

统计面板页用于角色卡片维度的集中统计与记录查询。

主要区块：

- 阶梯分布：按不同统计维度查看角色分布。
- 节日人选：按节日查看角色分层，支持高星合并低星等选项。
- 间隔记录：查看 Ban 间隔、Banner 相关等记录；特殊统计：查看各团 VS、团分、FES 等统计。
- 年份统计：在花色统计后按自然年或运营年查看角色阶梯分布，底部显示团汇总，可按年份或统一选择计入附属 VS。卡面模式每个角色一列，从上到下按时间排列，可选择显示出卡日期，右上角红色缎带标记限定类型。默认仅统计四星，可勾选三星、二星；常驻与限定默认均选中，可分别筛选，剧场版卡计入限定并标记为期间限定。

常见控制：

- 统计截止活动 ID：桌面端可在顶栏调整；手机端展开统计菜单后可输入、使用加减按钮微调或复位。
- 筛选开关：如只看箱活、只看混活、统计联动、统计团分、统计 FES。
- 导出 PNG：各大区块均支持单独截图导出。
- 名称格式：在全局设置中选择缩写／单字显示。
- 年份归属：默认将新年活动及卡池计入下一自然年；运营年从周年活动至下一周年前一期，联动按开启日期归属，不受新年选项影响。

## 乐曲统计

乐曲页包含统计区和检索区两部分。

统计区：

- 各团歌曲统计：查看各团歌曲、2D、3D、APD 维度统计。
- VS 书下统计：支持图文模式切换、全局展开收起、分团体计数、2D/3D 计数。
- OC 书下统计：按团体和成员查看收录情况。
- Anvo 统计：支持展开收起与显示模式切换。
- 双人歌曲统计：按团体和角色组合查看双人曲。

检索区：

- 关键词搜索：支持曲名、作词、作曲、编曲。
- ID 搜索：使用 # 前缀（示例：#241）。
- 假名/罗马音搜索：支持按发音检索。
- 条件筛选：团体筛选、MV 类型筛选。
- 难度排序：支持难度字段选择与升降序/默认模式切换。

## 移动端与交互说明

- 三个页面均适配移动端布局。
- 手机端隐藏顶部导航，使用随屏幕宽度伸缩、始终居中的底部悬浮切换栏；按住滑块可直接跨越多页，活动页的圆形“源”入口独立位于其右侧，切页时切换栏不会移动。卡片与乐曲统计的页面菜单随顶栏隐藏而上移，直达顶部按钮与底部切换栏水平齐平。
- 页面内统计菜单支持收起与展开。
- 大多数统计卡片支持一键展开/收起与导出。
