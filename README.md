# pjsk-planner 用户手册

本项目是面向《世界计划》的非官方数据浏览与预测辅助站点，提供活动、卡片、乐曲三大页面，并带有本地预测数据源管理。

## UI 开发规范

维护者请参阅 [UI 开发规范](docs/ui-system.md)。

## 页面总览

桌面端顶部导航、手机端底部悬浮切换栏均可进入 3 个页面：

- 统计面板：角色卡片统计、节日人选、间隔记录、特殊统计。
- 历史活动一览：活动时间轴、筛选、预测编辑与悬浮统计。
- 乐曲统计：多维乐曲统计与乐曲检索。

## 活动页数据源

数据源菜单只在历史活动页显示：桌面端位于顶栏右侧；手机端点击底部切换栏右侧的圆形“源”按钮，菜单会向上展开，并随内容增减向上伸缩；内容超出屏幕可用高度时可在菜单内滚动。预测编辑器打开时不可切换数据源。

- 导入：导入 JSON，作为新的预测数据源。
- 导出：导出当前数据源。
- 预测截图：导出预测区间 PNG，可选择是否包含生日行。
- 新建：新建空白数据源，或复制当前数据源。
- 删除：删除当前数据源（至少保留一个数据源）。
- 重命名与排序：支持重命名、上下移动和拖拽排序。

用户名会用于导出命名和本地数据源命名。

## 历史活动一览

历史活动页用于查看活动列表、编辑预测以及快速观察统计结果。

核心能力：

- 活动导航：可快速跳到当前活动。
- 筛选面板：支持活动筛选与卡片筛选两种模式。
- 常用筛选条件：活动类型、卡池类型、活动节日、活动属性、活动团体等。
- 联动卡池显示切换：可隐藏或显示联动卡池。
- 预测状态标记：区分待预测与已预测。

预测编辑：

- 打开某活动后可进入预测编辑器。
- 可配置活动类型、卡池性质、活动属性、Ban 主。
- 可编辑阵容中的角色、稀有度、属性、技能。
- 支持 World Link 特殊规则（人选锁定、仅调整属性等）。

悬浮统计：

- 预测编辑打开时，可启用悬浮统计面板。
- 可选择最多 6 个统计面板显示。
- 支持拖动、收起、重置布局。
- 可配置属性统计人选、日挑配队人选、节日单选等。

## 统计面板

统计面板页用于角色卡片维度的集中统计与记录查询。

主要区块：

- 阶梯分布：按不同统计维度查看角色分布。
- 节日人选：按节日查看角色分层，支持高星合并低星等选项。
- 间隔记录：查看 Ban 间隔、Banner 相关等记录；特殊统计：查看各团 VS、团分、FES 等统计。

常见控制：

- 统计截止活动 ID：桌面端可在顶栏调整；手机端展开统计菜单后可输入、使用加减按钮微调或复位。
- 筛选开关：如只看箱活、只看混活、统计联动、统计团分、统计 FES。
- 导出 PNG：各大区块均支持单独截图导出。
- 名称格式：支持缩写/单字显示。

## 乐曲统计

乐曲页包含统计区和检索区两部分。

统计区：

- 各团歌曲统计：查看各团歌曲、2D、3D、APD 维度统计。
- VS 书下统计：支持图文模式切换、全局展开收起、分团体计数、2D/3D 计数。
- OC 书下统计：按团体和成员查看收录情况。
- Anvo 统计：支持展开收起与显示模式切换。
- 双人歌曲统计：按团体和角色组合查看双人曲。

检索区：

- 关键词搜索：支持曲名、作词、作曲、编曲。
- ID 搜索：使用 # 前缀（示例：#241）。
- 假名/罗马音搜索：支持按发音检索。
- 条件筛选：团体筛选、MV 类型筛选。
- 难度排序：支持难度字段选择与升降序/默认模式切换。

## 移动端与交互说明

- 三个页面均适配移动端布局。
- 手机端隐藏顶部导航，使用随屏幕宽度伸缩、始终居中的底部悬浮切换栏；按住滑块可直接跨越多页，活动页的圆形“源”入口独立位于其右侧，切页时切换栏不会移动。卡片与乐曲统计的页面菜单随顶栏隐藏而上移，直达顶部按钮与底部切换栏水平齐平。
- 页面内统计菜单支持收起与展开。
- 大多数统计卡片支持一键展开/收起与导出。

## 数据与说明

- 本站部分内容包含本地预测数据，预测结果仅供参考。
- 数据源切换不会自动覆盖其他数据源内容，请注意当前激活源。
